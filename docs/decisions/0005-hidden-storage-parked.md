# 0005. Hidden storage is parked

- **Status:** adopted in rules v0.5 (draft). Numbers await the simulator.
- **Date:** 2026-11-14
- **Rules section:** §8

## Context

v0.4 listed hidden storage as a later variant and asked whether it is worth testing once open play is understood.

## Decision

Hidden storage is not planned. Storage stays public.

## Why

- The first rule of §1 says everything a player plans around is visible, and a rival's stock is exactly what a player reads to judge whether an order will fill.
- The game already has one well-placed secret, the current round's plan. Hiding storage as well would turn that read into a guess.

## Alternatives considered

- **Test hidden storage as a variant now.** Rejected: it spends simulator and playtest time on a rule that contradicts the organising principle.

## What would change this

It comes back only if moderated play shows that open storage lets players work out each other's orders exactly, so that planning feels solved.
