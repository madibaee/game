# Simulator reports

Simulator results that drove a change to a rule or a number go here, one file per finding, so the changelog and decision notes can link to the evidence. Name each file by date and topic, for example `2026-11-20-import-cap.md`, and say which rules tag and which `config/economy.json` preset it was run on.

The simulator itself, and its full generated reports, live in `sim/`.
